# 留言板（旧网站）

:::tip 注意
本页面仅供展示旧网站的留言板内容，如果您想在这个网站评论，请在其他页面（如[《关于晨叶梦春》](/about-me/)、[《关于 Blog》](/about-blog/)）评论 (｡･ω･｡)
:::

根据<a target="_blank" rel="noopener external nofollow noreferrer" href="https://mp.weixin.qq.com/s/0ZlQLQILaXwpklpef88eJg">《互联网跟帖评论服务管理规定》</a>，由于<a target="_blank" rel="noopener external nofollow noreferrer" href="https://wuziqian211.icoc.vc/">梦春酱的旧网站</a>使用的是==免费域名==，所以旧网站在发布这个规定之后就==**不支持留言功能与内容显示**=={.error}了 (´；ω；\`)
对此，梦春酱创建了这个页面，并且复制了旧网站的留言到这里 (=・ω・=)

由于技术限制，梦春酱只复制了留言的内容及管理员回复、用户当时填写的昵称与 B 站 UID，而没有复制旧网站中用户的头像 (´；ω；\`) 同时，原网站的账号也是没有被复制到本网站的评论系统的，所以**您不能在本站的评论区中直接使用以前的登录信息来登录，需要注册一个新的账号**哟 awa

- 如果您当时在旧网站的留言板==填写了 B 站 UID=={.tertiary}，那么在本站的评论区中，点击您的昵称就会跳转到您的 B 站个人空间，头像也是您**当前使用**的 B 站头像哟 (^・ω・^)
- 如果您==没有填写 B 站 UID=={.error}，那么显示的头像就是随机 B 站头像 qwq

:::tip 提示
如果您注册了**本站**的评论系统的账号，就可以修改与删除您**使用这个账号**在本站的评论；但是这个页面上显示的评论均以==未登录账号=={.error}的状态发布，所以您**不能直接修改与删除**这个页面的评论，您可以私信梦春酱来帮助您 (｀・ω・´)
:::
